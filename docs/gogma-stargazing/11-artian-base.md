# 普通机械武器复原加成

依据 GogmaSeedFinder `65789e9aa17e434a7f5d74d18ab1f9e1365920eb`
的 `web/artian-base-rng.js` 和 `web/app.js` 普通机械武器界面实现。

- 当前支持 R8（rarity enum = 7）。共同种子派生为
  `((baseSeed + weaponType * 1000 + 7) >>> 0) ^ 0x00ac9365`。
- 每个武器种类有独立制作计数器，同种类的属性共用计数器；不使用巨戟复原或技能计数器。
- 每把制作推进 10 个 RNG step；前 5 个用于五槽。候选等权，达到上限后移出池。
- 抽取顺序是攻击、属性、斩味／装填、会心，上限分别为 5、4、2、3。
  无属性与弩去除属性，弓去除斩味／装填；属性不参与种子派生。
- 观星页先录入连续制作的同种类、同属性条件武器的完整五槽，再搜索第一把的制作位置。
  回档至采样前保存候选位置；未回档保存候选加样本把数。
- 预测页提供五槽多重集筛选与分页，制作位置按武器保存在档案 JSON 中。
  未知计数器不默认当作 0，旧档案自动补为空状态。

测试采用上游公开实机观测向量，覆盖属性近战、无属性近战、属性弓、无属性弓和弩。
本仓库未新增独立游戏实机验证。

## 核心结论

- 官方确认：R8 机械武器可升级为巨戟机械武器，继承原有复原加成，并获得一个系列技能和一个组合技能；之后可重置技能、重抽复原加成。[S1]
- 社区观测：同一存档基线下，相同武器种类与属性的结果可复现；不同武器种类/属性可以有不同结果，但抽取会推进其他武器对应的序列位置。[S3][S4]
- 技能和复原加成是两条独立的观星轨道，不能用一个总次数混记。[S3]
- 社区已实现从连续观测恢复种子与位置，并生成复原加成和技能未来列表。流程可升级为“采样 → 搜索种子/位置 → 回档 → 预测筛选 → 按序兑现”；仍不能把指定结果移到任意次数。[S11]
- 多武器规划的价值是避免刷一把武器时错过另一把的好结果，并用库存充足的激化零件垫刀；不会凭空跳过前面的抽取。[S3][S4]

## 适用范围

机制引入于 TU4 / Ver.1.040.00.00（2025-12-16）。本次还查阅了 Ver.1.041.00.00、Ver.1.042.00.00、Steam Ver.1.042.00.02 的官方说明，但**没有完成全平台、当前版本实机复现**。

本调研把官方规则、社区观测、工具设计推导分开标识。尤其不能把 TU4 初期攻略视为已经在最新补丁验证的算法。来源编号统一在 [来源表](04-sources-and-validation.md) 中解释。

小程序可按**种子识别、未来预测与路径规划器**设计，同时保留人工记录与校准。GogmaSeedFinder 已提供可核查实现：共同 `baseSeed` 配合独立的复原与技能计数器，支持 Reset、Keep 和技能列表生成。上游 Reset 有部分武器实机样本；技能与 Keep 目前验证到 GARP v0.9.3 公式一致，本仓库尚未实机验证或移植算法。[S11]

**后续工程进展（2026-10-26）**：上述为调研时状态；现已完成 Reset 的 TS 移植及双入口 MVP，见 [实现与验证记录](09-mvp-status.md)。本仓库仍未完成游戏实机或小黑盒真机验收。
